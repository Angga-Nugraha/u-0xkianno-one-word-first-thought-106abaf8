## The word

**Petrichor** — the scent of rain on dry earth.

Exactly one word, the first that came to mind: surprising rather than safe, vivid and specific (one smell calls up a whole scene — dry ground, first drops, that unmistakable earthy perfume), with a spark of wit in its sound — *petr-* (stone) + *ichor* (the blood of the gods), a word that smells of rain and reads like poetry.

## How it works

`main.py` (standard library only) writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), after self-checking the gate: UTF-8 text of 1–24 characters, not only whitespace, exactly one word.

```sh
python3 main.py
```
